A modern, responsive personal portfolio website built to showcase my software development skills and projects. This portfolio highlights my journey as a Full-Stack Developer and serves as a central place for employers and collaborators to learn more about my work.

## About the Project

This portfolio was created using **HTML5**, **CSS3**, and **JavaScript** to provide a clean, responsive, and user-friendly experience across desktop and mobile devices.

The website includes:

- Home page with a professional introduction
- About Me section
- Skills showcase
- Featured Projects section
- Downloadable résumé
- Contact page
- Smooth scrolling and fade-in animations
